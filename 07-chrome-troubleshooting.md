# Ticket 007: Chrome & System Performance Troubleshooting

## Scenario
A simulated user reported that their computer and web browser were running slowly.

## Environment
- Windows 10
- Google Chrome
- Windows Task Manager

## Issue
The computer was experiencing slow performance and elevated memory usage.

## Troubleshooting & Resolution
1. Opened Task Manager to review CPU, memory, disk, and network usage.
2. Identified elevated memory usage at approximately 70%.
3. Reviewed installed applications and removed unnecessary software.
4. Cleared Google Chrome browsing data and cached files.
5. Reviewed startup applications and disabled unnecessary programs.
6. Restarted the computer and checked Task Manager again.
7. Memory usage decreased to approximately 62%.

## Result
System performance improved after cleanup and optimization. Memory usage decreased from approximately 70% to 62%.
