# Ticket 001 — Password Reset & Account Recovery

## Ticket Summary
A simulated user reported being unable to sign in to their company account and needed assistance regaining access.

## Environment
- Microsoft Azure
- Microsoft Entra ID
- User account management

## Issue
The user was unable to log in because of a password-related issue.

## Troubleshooting & Resolution
1. Located the user's account in Microsoft Entra ID.
2. Verified the correct user account.
3. Initiated a password reset.
4. Generated a temporary password for the user.
5. Instructed the user to sign in using the temporary credentials.
6. The user was prompted to create a new password.
7. Verified with the user that the new password worked and account access was restored.

## Resolution
User successfully regained access to the account after the password reset. Ticket resolved.

- Microsoft Entra ID
- Password Reset
- Account Recovery
- User Verification
- Identity & Access Management (IAM)
- Help Desk Communication
