# Ticket 003 — Department Transfer

## Ticket Summary
A simulated employee needed their access updated after transferring from the Marketing department to the Sales department.

## Environment
- Microsoft Azure
- Microsoft Entra ID
- Security Groups
- Identity & Access Management

## Request
Update the user's department access by removing their Marketing access and providing access to the Sales department.

## Resolution Steps
1. Located Sarah Johnson's user account in Microsoft Entra ID.
2. Reviewed the user's existing group memberships.
3. Removed the user from the Marketing security group.
4. Created the Sales security group.
5. Added the user to the Sales security group.
6. Verified the updated group membership.

## Resolution
The user's department access was successfully updated. Marketing access was removed and Sales access was granted.

- Identity & Access Management (IAM)
