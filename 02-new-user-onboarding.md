# Ticket 002 — New User Onboarding

## Ticket Summary
A simulated new employee needed a company user account and access to the Marketing department.

## Environment
- Microsoft Azure
- Microsoft Entra ID
- Security Groups
- User Account Management

## Request
Create a new user account for the employee and provide the appropriate department access.

## Resolution Steps
1. Opened Microsoft Entra ID.
2. Navigated to user management.
3. Created a new user account for Marcus Lee.
4. Verified the user's account information.
5. Located the Marketing security group.
6. Added Marcus Lee as a member of the Marketing group.
7. Verified that the user appeared in the group's membership list.

## Resolution
The new user account was successfully created and assigned to the Marketing security group.

- Microsoft Entra ID
- User Provisioning
- New User Onboarding
- Security Group Management
- Identity & Access Management (IAM)
- Access Control
- Help Desk Ticket Documentation
