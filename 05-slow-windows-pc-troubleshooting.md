# Ticket 005 — Slow Windows PC Troubleshooting

## Ticket Summary
A Windows computer was experiencing slow performance and applications were taking longer than expected to open.

## Environment
- Windows PC
- Lenovo Laptop
- Windows Task Manager
- Windows Storage Settings
- File Explorer

## Issue
The computer was running slowly during normal use.

## Troubleshooting Steps
1. Opened Task Manager to review system resource usage.
2. Identified memory usage between approximately 77–79%.
3. Reviewed the Performance tab and found that the computer had 4 GB of installed RAM, with approximately 3.4 GB usable.
4. Checked CPU and disk utilization for abnormal activity.
5. Reviewed startup applications and disabled unnecessary high-impact startup programs.
6. Checked the Windows C: drive and discovered only 1.74 GB of 117 GB was available.
7. Used Windows Storage settings to investigate disk usage.
8. Reviewed the Downloads folder and sorted files by size.
9. Identified and removed an unused Microsoft Visio installation file that was approximately 3.4 GB.
10. Uninstalled unused applications and old software.
11. Increased available storage from approximately 1.74 GB to 8.41 GB.
12. Restarted the computer and reviewed system performance again.
13. Tested normal web browsing and confirmed improved computer performance.

## Resolution
Removed unnecessary files and unused applications, disabled unnecessary startup programs, and recovered approximately 6.67 GB of storage. After restarting and testing the computer, system responsiveness improved.

The computer still has only 4 GB of installed RAM, which remains a hardware limitation and may affect performance during heavier multitasking.
